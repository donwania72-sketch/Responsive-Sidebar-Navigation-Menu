# Responsive Sidebar Navigation Menu

## 📖 Description
Responsive Sidebar Navigation Menu is a clean and modern navigation menu designed for websites and web applications. It features a slide-in sidebar with smooth transitions and a hamburger menu icon for smaller screens. The menu improves user experience by providing easy access to different sections of the website.

## 🚀 Features
- Responsive design for all screen sizes
- Slide-in and slide-out sidebar menu
- Hamburger menu icon
- Close (X) button for sidebar
- Clean and minimal UI
- Smooth animations and transitions

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Menu Sections
- Home
- About
- Contact

## 🎯 Purpose
This project is ideal for:
- Personal portfolios
- Business websites
- Practice of responsive layouts
- Learning sidebar navigation functionality

## 📸 Preview
The sidebar appears from the left side when the menu icon is clicked and can be closed using the cross button.

## 📌 How to Use
1. Clone or download the project
2. Open `index.html` in your browser
3. Click the menu icon to open the sidebar
